# 📄 PaperLens — AI 논문 요약기

> 생성형 AI를 활용한 학술 논문 자동 요약 웹 애플리케이션

🔗 **[바로 사용하기](https://sangchul-lee02.github.io/paperlens/paper_summarizer.html)**

---

## 소개

PaperLens는 학술 논문 PDF를 업로드하면 **Google Gemini AI**가 자동으로 핵심 내용을 분석하고 요약해주는 웹 애플리케이션입니다.

영국 대학원(Middlesex University / Loughborough University) 입학을 준비하면서 **Cover Letter와 CV 작성 중 스포츠 분석 관련 논문을 빠르게 파악해야 할 필요성**을 느껴 직접 개발했습니다.

---

## 주요 기능

| 기능 | 설명 |
|------|------|
| 📄 PDF 업로드 | 드래그 앤 드롭 또는 클릭 업로드 (최대 20MB) |
| 📝 핵심 요약 | 논문 핵심 내용을 3~4문장으로 한국어 자동 요약 |
| 🎯 연구 목적 | 연구의 목적과 문제 제기 자동 추출 |
| 🔬 연구 방법론 | 실험 설계 · 데이터 수집 · 분석 기법 태그 생성 |
| 💡 주요 결론 | 핵심 발견과 연구 의의 요약 |
| 🏷️ 키워드 | 1차 · 2차 키워드 자동 분류 |
| 📋 복사 기능 | 섹션별 복사 및 전체 일괄 복사 |

---

## 사용 기술

- **Frontend** : HTML5, CSS3, Vanilla JavaScript
- **AI API** : Google Gemini 2.5 Flash Lite
- **PDF 처리** : PDF.js (Mozilla)
- **배포** : GitHub Pages

```
한국공학대학교 데이터사이언스경영학과 재학 중
목표 : 스포츠 전력분석관 (EPL Performance Analyst)
```

이를 해결하기 위해 **생성형 AI(Claude + Gemini)를 활용해 직접 개발**했습니다.
